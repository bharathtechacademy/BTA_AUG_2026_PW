🧑‍🏫 What You'll Learn

  • 📜 JavaScript Fundamentals: Data Types, Variables, Operators, Functions, OOPS Concepts, Modules, Exception Handling, and Best Practices
  • 📘 TypeScript Fundamentals & Advanced Libraries: TypeScript vs JavaScript, Data Types, Functions, OOPS Concepts, Advanced Libraries for Excel, CSV, PDF, DB Operations
  • 🎭 Playwright Fundamentals: Installation, Configuration, Locators, Web Actions, Forms, Popups, Alerts, Frames, File Operations, Assertions, Screenshots, Videos, Parallel Testing
  • 🏗️ Automation Frameworks Design: Playwright Test TDD Framework (Page Object Model, Utilities, Logger, Test Data Management, Allure Reports) & Playwright Cucumber BDD Framework (Gherkin Syntax, Feature Files, Step Definitions, Hooks, World.ts)
  • 🔗 API Testing: Postman with Postbot Automation, Newman CLI Integration, Playwright API Testing, Authentication, Response Validation, API Framework Design, Apache JMeter Performance Testing
  • 🤖 Gen AI & MCP in Software Testing: AI Copilots, LLMs, Generative AI, MCP Servers, GitHub Copilot, Cursor, Windsurf, Antigravity, Ollama, GPT4All, Prompt Engineering, AI-Augmented Testing Workflows
  • 🐙 Source Code Management: Git & GitHub, Version Control, Branching Strategies, Collaborative Workflows, Azure Repos
  • 🚀 CI/CD & Build Management: Azure Pipelines, Automated Builds, Test Execution, Monitoring Results
  • 📅 Agile Project Setup in Azure TFS: Azure DevOps Projects, Agile SDLC, Scrum Methodology, Sprint Planning, User Stories, Test Management, Defect Management
  • 🛠️ Hands-on Tools: VS Code, Playwright, Postman, Newman, JMeter, Ollama, Llama 3.2, GitHub Copilot, Cursor, Git, GitHub, Azure DevOps,PostgreSQL
